# Log File Analyzer

A Python-based log analysis tool that processes server log data and generates useful statistics and insights.

## Features

- Filter logs by log level
- Count INFO, WARNING, and ERROR logs
- Find the most active user
- Group errors by hour
- Calculate error rate
- Find the top 5 most common error messages
- Identify the time period with the most errors
- Generate a formatted summary report

## Technologies Used

- Python
- Lists
- Dictionaries
- List Comprehensions
- Sets
- Tuples
- Functions
- DateTime
- Sorting
